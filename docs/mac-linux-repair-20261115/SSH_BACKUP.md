# SSH 备份维护候选

本仓库保留参数化的备份SSH账户采用脚本 `scripts/adopt_backup_ssh_account.py`。本文说明源码能力与待验收边界；私人现场记录继续保留在所有者本地原目录和恢复提交链中。

输入通过stdin提供配置路径、账户目录、用户名、服务、监听端口、公钥、配置基线摘要和验证超时。实际值必须来自原维护任务的已核实方案，不在公开文档中保存真实连接资料。

脚本要求root及显式 `--approved-adoption`，会创建账户和授权文件、替换传入的SSH配置并reload传入服务。它没有只检查模式；本次Git治理未执行这些动作。

源码包含配置备份、摘要复核、候选语法/策略检查、有界确认和未确认时的恢复分支。这些实现不是完整事务安全验收：账户创建后身份记录的失败窗口、恢复阶段阻塞、并发配置替换与恢复二次失败仍须独立离线故障注入核对。

后续源码安全修复应替代系统接口，在合成配置和账户模型中验证创建半成功、reload失败、确认超时、恢复受阻及并发漂移，保留原始错误与明确的部分恢复状态。实际采用由原维护任务另行授权并核对服务身份；源码交付不产生运行采纳或真实网络验收结论。
